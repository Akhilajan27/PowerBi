# COVID-19 Data Analysis Dashboard
## Overview
This project presents a detailed analysis of the COVID-19 outbreak using an interactive Power BI dashboard. The data was sourced from Kaggle and highlights critical metrics such as infection trends, recovery rates, and vaccination progress.
## Features
- **Interactive Visualizations**: Provides dynamic insights into global and country-specific COVID-19 data.
- **Key Metrics**: Tracks active cases, recoveries, deaths, and fatality rate.
- **Filters**: Allows users to drill down into specific timeframes, regions, and other parameters.
## Data Source
The dataset used for this analysis was obtained from **[Kaggle](https://www.kaggle.com)**, a leading platform for datasets and machine learning projects. The data includes:
- Global COVID-19 cases
- Country-wise details on infections and recoveries
